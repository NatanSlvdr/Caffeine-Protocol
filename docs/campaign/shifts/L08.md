# L08: The Usual Suspect

Act I: Query · 6 tables · 4 seeds

A guest asks for “the usual”. Query has never met them before. Better to ask Niko than to guess. Get this right and there’s a badge in it.

**Goal.** Some customers order “the usual”, which Query can’t interpret. Guessing would send the wrong drink to the kitchen, so an unclear order must be cleared up before anything is written.

**Lesson.** An unclear request contains Ambiguous. Before taking paper or starting For item in order, use If Ambiguous IN Orders and Help. Niko replaces the heard orders with a clarification.

**Stars.** One for serving every seed, two for 31 blocks or fewer, three for also finishing in 410 executed steps or fewer. The reference uses 29 blocks.

## Customers in the first seed

- “the usual”, then “coffee with sugar”
- “something warm”, then “tea”
- “regular”, then “tea with 2 sugars”
- “coffee”
- “coffee with 1 sugar”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```
