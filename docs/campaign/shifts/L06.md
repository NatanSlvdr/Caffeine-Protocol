# L06: For Each Their Own

Act I: Query · 6 tables · 3 seeds

Two friends arrive together and order at once. The kitchen needs one ticket per drink. Sharing is caring, just not on paper.

**Goal.** Some customers order several drinks at once. The kitchen needs a separate ticket for every drink.

**Lesson.** For item in order visits each drink in the order. Take a fresh sheet, write that item, deposit it, and return to the register on every pass.

**Stars.** One for serving every seed, two for 23 blocks or fewer, three for also finishing in 264 executed steps or fewer. The reference uses 21 blocks.

## Customers in the first seed

- “coffee and tea”
- “two coffees”
- “two teas”
- “coffee”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF sugar IN item
    IF negation IN item
      WRITE 0 sugar
    ELSE
      WRITE 1 sugar
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```
