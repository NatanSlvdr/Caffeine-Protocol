# L05: Sugar, No Sugar

Act I: Query · 5 tables · 3 seeds

With sugar, please! Without sugar, thanks! Query hears “sugar” loud and clear… and also that sneaky “without”.

**Goal.** Some customers ask for sugar, and some say “without sugar”: they mention sugar but don’t want any. Every ticket must match what the customer meant.

**Lesson.** If Sugar IN Orders catches a request for sugar, and Write 1 Sugar puts it on the held paper. “Without sugar” still contains Sugar, plus Negation: inside that If, test If Negation IN Orders, then Write 0 Sugar or Write 1 Sugar.

**Stars.** One for serving every seed, two for 21 blocks or fewer, three for also finishing in 301 executed steps or fewer. The reference uses 19 blocks.

## Customers in the first seed

- “coffee with sugar”
- “coffee without sugar”
- “tea with sugar”
- “tea without sugar”
- “coffee no sugar”
- “coffee, but no sugar please”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
TAKE UP
IF tea IN CUSTOMER SPEECH
  ITEM tea
ELSE
  ITEM coffee
END
IF sugar IN CUSTOMER SPEECH
  IF negation IN CUSTOMER SPEECH
    WRITE 0 sugar
  ELSE
    WRITE 1 sugar
  END
END
MOVE RIGHT 1
DEPOSIT RIGHT
MOVE LEFT 1
JUMP listen
```
