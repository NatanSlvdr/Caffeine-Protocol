# L14: Special Delivery

Act III: Porter · 2 tables · 3 seeds

The cutscene _The Floor Robot_ plays before this shift: School starts soon, and Pip doesn’t want a robot on his floor.

Meet Porter, the brand-new floor robot. Pip points at a finished drink and the guest waiting for it.

**Goal.** Finished drinks wait at pickup, and each ticket names the table that ordered it. Porter walks off without reading it.

**Lesson.** Porter takes over the room. Wait for Orders claims a ready drink and Take down picks it up from pickup. Store the order’s table in Var A: Move to Var A walks Porter there by itself, and Deposit up serves it.

**Stars.** One for serving every seed, two for 83 blocks or fewer, three for also finishing in 753 executed steps or fewer. The reference uses 81 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text

LISTEN

FUNCTION recipe
  MOVE RIGHT 1

    MOVE RIGHT 3
    USE UP

  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5

  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END

END
```

### Porter (floor)

```text
STORE var2 FROM here
LISTEN
TAKE DOWN
CALL deliver
CALL clear
REPEAT
FUNCTION deliver
  STORE var1 FROM table
  MOVE var1
  DEPOSIT UP
  MOVE var2
  RETURN
END
FUNCTION clear
  WAIT DIRTY
  STORE var1 FROM table
  MOVE var1
  TAKE UP
  MOVE var2
  MOVE RIGHT 1
  DEPOSIT DOWN
  MOVE LEFT 1
  RETURN
END
```
