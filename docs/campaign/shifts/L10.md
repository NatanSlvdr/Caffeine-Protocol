# L10: Steep Thoughts

Act II: Brew · 1 table · 3 seeds

A tea order reaches the kitchen. Brew must pick a different recipe without forgetting how to make coffee.

**Goal.** Tickets now ask for coffee or tea, and the two drinks use different ingredients. Brew must make whichever drink each ticket asks for.

**Lesson.** Tea uses leaves, water, and steeping. Leaves skip the grinder: branch on the ticket and walk tea straight to the sink.

**Stars.** One for serving every seed, two for 48 blocks or fewer, three for also finishing in 208 executed steps or fewer. The reference uses 46 blocks.

## Customers in the first seed

- “coffee, 0 sugars”
- “tea, 0 sugars”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
LISTEN

```
