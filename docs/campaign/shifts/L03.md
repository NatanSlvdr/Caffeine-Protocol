# L03: Coffee or Tea?

Act I: Query · 4 tables · 3 seeds

Tea has joined the menu and the great debate begins. Some guests still want coffee, others would like tea. Query has to listen closely.

**Goal.** Customers now order either coffee or tea. Each ticket must name the drink the customer actually asked for.

**Lesson.** Conditions check what the customer said. Use If Tea IN Orders to test it, then Write Tea or Write Coffee. No loop is needed yet.

**Stars.** One for serving every seed, two for 12 blocks or fewer, three for also finishing in 27 executed steps or fewer. The reference uses 10 blocks.

## Customers in the first seed

- “coffee”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
LISTEN
TAKE UP
IF tea IN CUSTOMER SPEECH
  ITEM tea
ELSE
  ITEM coffee
END
MOVE RIGHT 1
DEPOSIT RIGHT
MOVE LEFT 1
```
