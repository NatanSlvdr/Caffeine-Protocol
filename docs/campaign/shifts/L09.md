# L09: A Brew-tiful Friendship

Act II: Brew · 1 table · 3 seeds

The cutscene _A Second Pair of Hands_ plays before this shift: Query earns its badge, and Moka won’t have a robot in Lou’s kitchen.

Brew rolls into the kitchen, eager and a little squeaky. Moka watches from the doorway, arms crossed, while Pip keeps the drinks moving.

**Goal.** Brew’s coffee recipe is almost complete, but it never runs the coffee machine, so the beans are never ground. Every coffee must be ground, brewed and left at pickup.

**Lesson.** Brew waits for Query’s tickets at the order handoff and makes each drink: Take up the beans at storage, Use up the coffee machine to grind them, Take up water at the sink, Use up the machine again to brew, then Deposit up at pickup. Pip still serves the room.

**Stars.** One for serving every seed, two for 45 blocks or fewer, three for also finishing in 212 executed steps or fewer. The reference uses 43 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```
