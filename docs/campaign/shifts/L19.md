# L19: In a Hurry

Act IV: the whole crew · 16 tables · 3 seeds

The lunch rush brings people with a train to catch. They can’t wait behind the whole queue.

**Goal.** Some customers are in a rush, but their tickets look like everyone else’s, so their drinks wait in line. Every rush order needs Rush on its ticket, and a robot holding one must finish it before waiting for anything else.

**Lesson.** Customers in a rush say so: Query writes Rush on their ticket. Rush orders jump the queue, and whoever holds one handles it first. Brew can’t wait for another ticket while it holds a rush order, and Porter can’t wait or pick up another drink while it carries one.

**Stars.** One for serving every seed, two for 110 blocks or fewer, three for also finishing in 2677 executed steps or fewer. The reference uses 99 blocks. The target leaves room for the longer ways in listed in the [audit](../AUDIT.md), such as robots that keep batching.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  IF togo IN item
    WRITE togo
  END
  IF rush IN item
    WRITE rush
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
POSITION listen
LISTEN
CALL recipe
JUMP listen
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 1
  IF togo IN CUSTOMER SPEECH
    TAKE UP
  END
  MOVE RIGHT 1
  DEPOSIT UP
  MOVE RIGHT 1
  USE UP
  MOVE LEFT 9
  RETURN
END
```

### Porter (floor)

```text
STORE var2 FROM here
POSITION listen
LISTEN
TAKE DOWN
IF togo IN CUSTOMER SPEECH
  MOVE LEFT 12
  DEPOSIT DOWN
  MOVE var2
ELSE
  CALL deliver
  CALL clear
END
JUMP listen
FUNCTION deliver
  STORE var1 FROM table
  MOVE var1
  DEPOSIT UP
  MOVE var2
  RETURN
END
FUNCTION clear
  WAIT DIRTY
  STORE var1 FROM table
  MOVE var1
  TAKE UP
  MOVE var2
  MOVE RIGHT 1
  DEPOSIT DOWN
  MOVE LEFT 1
  RETURN
END
```
