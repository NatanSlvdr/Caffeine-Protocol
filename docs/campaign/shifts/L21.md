# L21: Espresso Yourself

Act IV: the whole crew · 16 tables · 3 seeds

The busiest day yet. Niko sits down with a coffee and trusts the whole team with the room.

**Goal.** The final service combines everything: group orders, coffee and tea, sugar, unclear requests, drinks to go, only four cups, customers in a rush, and closing time. Every guest must be served, every table cleared, and every robot stopped.

**Lesson.** Everything at once: groups, “the usual”, take-away orders, four cups, customers in a rush, and closing time.

**Stars.** One for serving every seed, two for 108 blocks or fewer, three for also finishing in 3347 executed steps or fewer. The reference uses 106 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF closed IN CUSTOMER SPEECH
  STOP
END
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  IF togo IN item
    WRITE togo
  END
  IF rush IN item
    WRITE rush
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
LISTEN
IF closed IN CUSTOMER SPEECH
  STOP
END
CALL recipe
REPEAT
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 1
  IF togo IN CUSTOMER SPEECH
    TAKE UP
  END
  MOVE RIGHT 1
  DEPOSIT UP
  MOVE RIGHT 1
  USE UP
  MOVE LEFT 9
  RETURN
END
```

### Porter (floor)

```text
STORE var2 FROM here
LISTEN
IF closed IN CUSTOMER SPEECH
  STOP
END
TAKE DOWN
IF togo IN CUSTOMER SPEECH
  MOVE LEFT 12
  DEPOSIT DOWN
  MOVE var2
ELSE
  CALL deliver
  CALL clear
END
REPEAT
FUNCTION deliver
  STORE var1 FROM table
  MOVE var1
  DEPOSIT UP
  MOVE var2
  RETURN
END
FUNCTION clear
  WAIT DIRTY
  STORE var1 FROM table
  MOVE var1
  TAKE UP
  MOVE var2
  MOVE RIGHT 1
  DEPOSIT DOWN
  MOVE LEFT 1
  RETURN
END
```
