# L07: One Lump or Two?

Act I: Query · 6 tables · 4 seeds

One sugar? Two? None at all, thank you very much? Our guests are getting specific, and “some sugar” won’t cut it anymore.

**Goal.** Customers now ask for an exact number of sugars, including zero. A simple yes or no is no longer enough.

**Lesson.** If Number IN item checks for a count. Store Var A = Number in item, then Write Var A Sugar writes the exact amount, including zero. Keep the sugar and negation checks for orders without numbers.

**Stars.** One for serving every seed, two for 28 blocks or fewer, three for also finishing in 383 executed steps or fewer. The reference uses 26 blocks.

## Customers in the first seed

- “coffee with 0 sugar”
- “coffee with 1 sugar”
- “tea with 2 sugars”
- “coffee with sugar”
- “tea without sugar”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```
