# L13: Double Trouble

Act II: Brew · 1 table · 3 seeds

The cutscene _Ninety-Two Degrees_ plays before this shift: Moka’s last morning in the kitchen, and the truth about the card.

Moka has hung up her apron, and Brew runs the kitchen alone. Its hands fit two cups now, and a little planning saves a lot of walking.

**Goal.** Brew can now carry two cups, but still makes one drink per trip. Brew must make two at a time, and drinks must leave in order and match their tickets.

**Lesson.** Brew now holds two cups. Claim two tickets before making them. Finished drinks leave in pickup order.

**Stars.** One for serving every seed, two for 59 blocks or fewer, three for also finishing in 499 executed steps or fewer. The reference uses 57 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
LISTEN
LISTEN

REPEAT
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3

    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5

  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END

END
```
