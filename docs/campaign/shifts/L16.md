# L16: Tea for Two

Act III: Porter · 4 tables · 3 seeds

Pip’s last shift before school starts. Porter’s new tray carries two items: two guests, one trip, zero spills. Hopefully.

**Goal.** Porter’s tray now holds two items, but Porter still carries one at a time. Porter must fill the tray before setting off, and anything beyond two won’t fit.

**Lesson.** Porter now holds two items. Take two drinks before serving, then clear both tables. The tray empties in the order it was filled.

**Stars.** One for serving every seed, two for 89 blocks or fewer, three for also finishing in 1505 executed steps or fewer. The reference uses 87 blocks.

**Challenges.** Optional, for no stars, and shown once the shift has been served.

- _Short legs._ Porter walks 800 tiles or fewer over the whole service. A guest drinks up in 12 s, sooner than Porter can walk back to the counter and out to the table again.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
POSITION listen

LISTEN

CALL recipe

FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 2
  DEPOSIT UP
  MOVE LEFT 8
  RETURN
END
```
