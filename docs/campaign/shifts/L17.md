# L17: To Go

Act IV: the whole crew · 16 tables · 3 seeds

The cutscene _Back to School_ plays before this shift: Pip’s first day of school, and Niko’s first day as just the owner.

Pip is back at school, and the robots run the café on their own. The morning commuters want their coffee to go.

**Goal.** Some customers order their drink to go. They don’t sit down: they wait by the door. Every to-go drink must reach the to-go shelf with a lid on.

**Lesson.** Some customers order to go. Query writes To go on their ticket: If To go IN item, then Write To go. Brew puts a lid on those drinks: Take up at the lids, between the sugar and pickup. Porter leaves them on the to-go shelf by the door: walk there and Deposit down. They go in paper cups, so there’s nothing to clear.

**Stars.** One for serving every seed, two for 96 blocks or fewer, three for also finishing in 2413 executed steps or fewer. The reference uses 94 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  IF togo IN item
    WRITE togo
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
POSITION listen
LISTEN
CALL recipe
JUMP listen
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 1
  IF togo IN CUSTOMER SPEECH
    TAKE UP
  END
  MOVE RIGHT 1
  DEPOSIT UP
  MOVE LEFT 8
  RETURN
END
```

### Porter (floor)

```text
STORE var2 FROM here
POSITION listen
LISTEN
TAKE DOWN
IF togo IN CUSTOMER SPEECH
  MOVE LEFT 12
  DEPOSIT DOWN
  MOVE var2
ELSE
  CALL deliver
  CALL clear
END
JUMP listen
FUNCTION deliver
  STORE var1 FROM table
  MOVE var1
  DEPOSIT UP
  MOVE var2
  RETURN
END
FUNCTION clear
  WAIT DIRTY
  STORE var1 FROM table
  MOVE var1
  TAKE UP
  MOVE var2
  MOVE RIGHT 1
  DEPOSIT DOWN
  MOVE LEFT 1
  RETURN
END
```
