# L12: Call Me Maybe

Act II: Brew · 1 table · 3 seeds

Brew has made the same recipes all morning. Let’s give those familiar steps a name, and just call them.

**Goal.** Brew’s recipe is one long run of steps in the middle of its routine, and soon Brew will need it more than once per trip. Serve every ticket as before, with the recipe written in one place.

**Lesson.** Move the recipe into Function recipe. Call recipe makes the drink on the oldest ticket Brew is holding.

**Stars.** One for serving every seed, two for 58 blocks or fewer, three for also finishing in 264 executed steps or fewer. The reference uses 56 blocks.

## Customers in the first seed

- “coffee, 0 sugars”
- “tea, 1 sugars”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
POSITION listen
LISTEN
CALL recipe
JUMP listen
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 2
  DEPOSIT UP
  MOVE LEFT 8
  RETURN
END
```
