# L18: Four Cups

Act IV: the whole crew · 16 tables · 3 seeds

The cup delivery is late, and there are only four cups in the whole café. Every cup has to come back and be washed before it can be used again.

**Goal.** Only four cups go round. When they run out, the next drink has to wait until a used cup is cleared and washed. Keep the cups coming back so every guest is served.

**Lesson.** There are only four café cups. Taking beans or leaves at storage uses a clean cup, and Porter drops the used ones in the sink. Use up at the sink washes them. When no clean cup is left, Brew waits at the sink until a used one comes back.

**Stars.** One for serving every seed, two for 98 blocks or fewer, three for also finishing in 2611 executed steps or fewer. The reference uses 96 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  IF togo IN item
    WRITE togo
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```
