# L15: Cups and Robbers

Act III: Porter · 2 tables · 3 seeds

Happy guests leave their empty cups behind. A clean table is the next guest’s first impression, so round them up.

**Goal.** Guests leave empty cups on their tables, and Porter walks up to them without picking them up. They need to go back to the sink before new guests arrive.

**Lesson.** Wait for Dirty cups picks a used cup. Walk to its table, Take it up, then carry it to the sink and Deposit down.

**Stars.** One for serving every seed, two for 83 blocks or fewer, three for also finishing in 753 executed steps or fewer. The reference uses 81 blocks.

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
LISTEN
LISTEN
CALL recipe
CALL recipe
REPEAT
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 2
  DEPOSIT UP
  MOVE LEFT 8
  RETURN
END
```

### Porter (floor)

```text
STORE var2 FROM here
LISTEN
TAKE DOWN
CALL deliver
CALL clear
REPEAT
FUNCTION deliver
  STORE var1 FROM table
  MOVE var1
  DEPOSIT UP
  MOVE var2
  RETURN
END
FUNCTION clear
  WAIT DIRTY
  STORE var1 FROM table
  MOVE var1
  TAKE UP
  MOVE var2
  MOVE RIGHT 1
  DEPOSIT DOWN
  MOVE LEFT 1
  RETURN
END
```
