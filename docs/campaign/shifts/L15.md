# L15: Cups and Robbers

Act III: Porter · 2 tables · 3 seeds

Pip is out buying his school books, so the empty cups are Porter’s job now. A clean table is the next guest’s first impression.

**Goal.** Guests leave their empty cups behind, and Porter only knows how to deliver. Every used cup has to go back to the sink before the next guest can sit down.

**Lesson.** Wait for Dirty cups picks a used cup. Walk to its table, Take it up, then carry it to the sink and Deposit down.

**Stars.** One for serving every seed, two for 85 blocks or fewer, three for also finishing in 766 executed steps or fewer. The reference uses 83 blocks.

## Customers in the first seed

- “coffee, 0 sugars”
- “tea, 1 sugar”
- “coffee, 2 sugars”
- “tea, 0 sugars”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
POSITION listen
LISTEN
LISTEN

CALL recipe
JUMP listen
FUNCTION recipe
  MOVE RIGHT 1
  TAKE UP
  IF coffee IN CUSTOMER SPEECH
    MOVE RIGHT 3
    USE UP
    MOVE RIGHT 5
  ELSE
    MOVE RIGHT 8
  END
  TAKE UP
  MOVE LEFT 5
  USE UP
  MOVE RIGHT 2
  STORE var1 FROM sugar
  FOR var1 TIMES
    TAKE UP
  END
  MOVE RIGHT 2
  DEPOSIT UP
  MOVE LEFT 8
  RETURN
END
```

### Porter (floor)

```text
STORE var2 FROM here
POSITION listen
LISTEN
TAKE DOWN
CALL deliver
CALL clear
JUMP listen
FUNCTION deliver
  STORE var1 FROM table
  MOVE var1
  DEPOSIT UP
  MOVE var2
  RETURN
END
FUNCTION clear
  WAIT DIRTY
  STORE var1 FROM table
  MOVE var1
  TAKE UP
  MOVE var2
  MOVE RIGHT 1
  DEPOSIT DOWN
  MOVE LEFT 1
  RETURN
END
```
