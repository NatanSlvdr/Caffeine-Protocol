# L11: A Spoonful of Sugar

Act II: Brew · 1 table · 3 seeds

The right drink is only half the order. Brew must remember the little extras that make it just right.

**Goal.** Tickets can request sugar, but Brew sends every drink out unsweetened. Each drink must match the sugar amount on its ticket.

**Lesson.** Orders now ask for sugar. Store the order’s sugar in Var A, then For Var A times, Take up at the sugar station drops in one cube.

**Stars.** One for serving every seed, two for 53 blocks or fewer, three for also finishing in 241 executed steps or fewer. The reference uses 51 blocks.

## Customers in the first seed

- “coffee, 0 sugars”
- “tea, 1 sugars”

## Reference programs

Written in the text-editor language. Moka runs the kitchen and Pip the floor until a robot takes the role over.

### Query (counter)

```text
POSITION listen
LISTEN
IF ambiguous IN CUSTOMER SPEECH
  HELP
END
FOR item IN heard orders
  TAKE UP
  IF tea IN item
    ITEM tea
  ELSE
    ITEM coffee
  END
  IF number IN item
    STORE var1 FROM number
    WRITE var1 sugar
  ELSE
    IF sugar IN item
      IF negation IN item
        WRITE 0 sugar
      ELSE
        WRITE 1 sugar
      END
    END
  END
  MOVE RIGHT 1
  DEPOSIT RIGHT
  MOVE LEFT 1
END
JUMP listen
```

### Brew (kitchen)

```text
LISTEN
MOVE RIGHT 1
TAKE UP
IF coffee IN CUSTOMER SPEECH
  MOVE RIGHT 3
  USE UP
  MOVE RIGHT 5
ELSE
  MOVE RIGHT 8
END
TAKE UP
MOVE LEFT 5
USE UP
MOVE RIGHT 2
STORE var1 FROM sugar
FOR var1 TIMES
  TAKE UP
END
MOVE RIGHT 2
DEPOSIT UP
MOVE LEFT 8
REPEAT
```
